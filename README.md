# 💱 Currency Converter

A simple and beautiful currency converter web app that shows **live & accurate exchange rates** between any two currencies. Built with pure HTML, CSS and JavaScript — no frameworks needed.

## ✨ Features

- 🌍 Convert between 100+ world currencies
- 🔄 Live exchange rates via a free API
- 🚩 Auto-updating country flags based on selected currency
- 🔁 One-click swap between "From" and "To" currencies
- 🎨 Modern glassmorphism UI with animated background
- 📱 Responsive and lightweight (no dependencies)

## 🛠️ Tech Stack

- **HTML5** – structure
- **CSS3** – styling (glassmorphism, animations)
- **JavaScript (Vanilla)** – logic & API calls
- **ExchangeRate API** – live rates (`api.exchangerate-api.com`)
- **Flags API** – country flags (`flagsapi.com`)

## 🚀 How to Use

1. Clone or download this repository.
2. Open `index.html` in any modern browser.
3. Enter an amount, pick "From" and "To" currencies.
4. Click **Get Exchange Rate** (or press Enter).
5. Use the swap icon (🔁) to quickly reverse currencies.

No build step, no installs — just open and use.

## 🌐 Live Demo

Open `index.html` locally, or host the folder on any static host (GitHub Pages, Netlify, Vercel).

## 📝 Notes

- Internet connection is required for live rates and flags.
- Rates are fetched from a free public API; availability depends on that service.
