# Premium Currency Converter

A simple and beautiful currency converter web app that shows live and accurate exchange rates between any two currencies. Built with pure HTML, CSS, and JavaScript - no frameworks needed.

## Features

- Convert between 100+ world currencies
- Live exchange rates via a free API
- Auto-updating country flags based on selected currency
- One-click swap between "From" and "To" currencies
- Modern glassmorphism UI with animated background
- Responsive and lightweight (no dependencies)

## Tech Stack

- HTML5 - structure
- CSS3 - styling (glassmorphism, animations)
- Vanilla JavaScript - logic and API calls
- ExchangeRate API - live rates (`api.exchangerate-api.com`)
- Flags API - country flags (`flagsapi.com`)

## Project Structure

```
Currency-Converter/
├── index.html   # Markup
├── style.css    # Styling
├── script.js    # Logic and API calls
└── codes.js     # Currency code list
```

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in any modern browser.
3. Select currencies, enter an amount, and convert.
